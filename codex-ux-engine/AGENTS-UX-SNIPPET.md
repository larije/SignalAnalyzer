## UX

For web UI/UX audits, reviews, design, or restyling, use `ux-engine` when available. Follow applicable project design documentation and component conventions.

Prioritize task completion, hierarchy, accessibility, responsive behavior, and relevant states. Preserve existing business behavior unless the user's request authorizes a behavior change. Audit/review and design-only requests do not authorize edits; direct implementation requests do.

Tie recommendations to evidence. Distinguish observed behavior, inference, and checks not performed. The skill's bundled design starter is optional and is not project policy.
